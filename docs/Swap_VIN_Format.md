# Steps to swap VIN format in Karavan's Syteline system 

Step one: Log in to Syteline - Factory Track then log in to the site that you want to modify.  

Step two: Click Form open and type ```Transaction Set Maintenance```.  

![Form Open](https://raw.githubusercontent.com/Karavan-Trailers/How-To-Sheets/main/img/SwapFormats/Step1.png)  

Step three: Click on the Transaction Set Maintenance form. (Not the gen2 one.)  

![Transaction Set Maintenance](https://raw.githubusercontent.com/Karavan-Trailers/How-To-Sheets/main/img/SwapFormats/Step2.png)  

Step four: Scroll to the bottom of the form you will then see VIN. Click that. 

![VIN](https://raw.githubusercontent.com/Karavan-Trailers/How-To-Sheets/main/img/SwapFormats/Step3.png)  

Step five: Click **Label Print Parameters**.  It **LOOKS** gray but you can click it.  

![Label Print Parameters](https://raw.githubusercontent.com/Karavan-Trailers/How-To-Sheets/main/img/SwapFormats/Step4.png)  

Step six: Click the **Label Name** dropdown and select the new label format.  

![Label Name Dropdown](https://raw.githubusercontent.com/Karavan-Trailers/How-To-Sheets/main/img/SwapFormats/Step5.png)  

Step seven: Click the **Save** button. (Looks like a floppy disk icon) 

![Save Button](https://raw.githubusercontent.com/Karavan-Trailers/How-To-Sheets/main/img/SwapFormats/Step6.png)  

Step eight: Close the Transaction Set Maintenance form.  

Step nine: Celebrate! You have successfully swapped the VIN format.
